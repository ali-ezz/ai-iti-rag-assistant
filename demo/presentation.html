Data & Chunking

Core Track — text-only corpus

  • 12 solved lab notebooks → cleaned Markdown — no OCR needed.
  • Split by Markdown section, then 320-word windows with 60-word overlap.
  • 264 chunks indexed into Chroma (cosine HNSW) — persisted for the API.
  • Metadata on every chunk: source, section, chunk_id → human-readable citations.

Grounding & anti-hallucination

Strict context-only generation

  • System prompt: answer ONLY from supplied context; refusal if insufficient.
  • Numbered [Source 1..k] context blocks; model must cite factual claims.
  • Low temperature (0.1), short max tokens, de-duplicated sources in API response.
  • UI shows expandable source cards under every answer.
